# PBR texture sets (SurfaceAppearance)

Original procedural sets for the hero kit, generated by `tools/textures/gen_pbr.py`
(`/tmp/claude-0/bpyenv/bin/python tools/textures/gen_pbr.py`, needs numpy + pillow; deterministic seeds).
Each set is four 512x512 PNGs: `<set>_color.png`, `_normal.png`, `_roughness.png`, `_metalness.png`.

| Set | Use | Base |
|---|---|---|
| `ashlar_stone` | tower/wall masonry: block courses (~2x1 studs), mortar, chips, faint moss | #6E6A63 |
| `plaster` | lime-plaster infill walls, cracks and stains | #BDB4A2 |
| `timber` | oak planks / beams, grain runs along U | #4A3426 |
| `slate_roof` | slate shingle rows, 1 stud tall | #474B53 |
| `clay_roof` | curved clay tile rows | #7A4A3A |
| `bronze` | aged bronze fittings, verdigris in recesses (metal 0.85, verdigris 0.1) | #7D6234 / #4E7E72 |
| `iron` | forged iron, rust speckle (metal 0.8, rust 0.2) | #3A3B3D / #5C4232 |

## Conventions

- All maps tile seamlessly. Kit UVs are world-scale box projection, 1 UV = 8 studs, so one tile covers 8x8 studs (64 px per stud).
- Color: sRGB albedo. Normal: tangent-space, OpenGL style (+Y up, green = up), flat = (128,128,255).
  Roughness and metalness: grayscale, white = rough / metal.
- Average tone matches the base hex (excluding accent areas such as mortar, moss, verdigris, rust).

## Upload

1. Studio > View > Asset Manager > Bulk Import, select all `*.png` in this folder, and publish as Images.
2. Copy each Image asset id and paste into `AssetManifest.Surfaces`, one entry per set:

```lua
ashlar_stone = {
    Color = "rbxassetid://0000000000",
    Normal = "rbxassetid://0000000000",
    Roughness = "rbxassetid://0000000000",
    Metalness = "rbxassetid://0000000000",
},
```
